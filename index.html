Strict Clinical Safety Boundary

No Autonomous AI Diagnosis: Per PS 047 guidelines, MediKiosk strictly acts as decision support. AI structures patient data, parses OCR, and alerts on red flags — the physician retains 100% diagnostic authority.

Core Architecture & Modules

STT AI
🎙️

Voice + Touch Dual Intake

Dual-mode patient interview supporting real-time Indian OPD code-switching between Hindi & English powered by Hosted Whisper ASR API.

AYUSH
🌿

Dashavidha Pariksha

Reusable AYUSH constitution profile and Ahara-Vihara (diet/lifestyle) structured history captured once and linked to ABHA ID.

OCR
📄

Prescription & Lab OCR

Google Vision API integration for extracting medicines, lab values, and complaints directly from handwritten or printed prescriptions.

TRIAGE
🚨

Red-Flag Alert System

Instant clinical triage detector that flags urgent symptoms and immediately elevates high-risk patients out of routine queues.

DOCTOR UI
⚡

30-Sec Summary Card

Physician dashboard with one-click per-section confirm/edit/reject controls, timeline visualization, and confidence indicators.

ABDM
🔐

Dynamic RBAC & ABDM

Multi-hospital dynamic Role-Based Access Control, JWT authentication, and ABDM/FHIR interoperable payload generation.

⚡ Technical Architecture (PS 047)

Frontend: React + Vite PWA (Service Worker + App Manifest for hospital tablet installability)
Backend: Python FastAPI (Async STT/OCR routing + JSONB decision tree evaluation)
Database: PostgreSQL (ABHA records, dynamic permissions matrix, patient session timelines)
AI Engine: Hosted Whisper API for Hindi-English ASR + Google Vision API for Handwritten Prescription OCR
Auth & RBAC: JWT with live Postgres permission check (`has_permission(role_id, module, action)`)
